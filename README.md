# KindFind (Android)

KindFind is an Android app concept for global lost-and-found matching:

- **Person B** finds an item/person and uploads details.
- They add identifiers (plate number, ID hints, wallet clues, clothing details, etc.), photos (field prepared), and contact info.
- **Person A** searches for what they lost using those identifiers.
- If matched, A and B contact each other directly to recover the lost item/person.

## Included in this scaffold

- Jetpack Compose UI
- "Upload Found Item" form
- Search by unique identifier/details/location
- Contact info shown in each post
- In-memory ViewModel data store with sample records
